# Token Speed Studio 实施计划

设计：`docs/superpowers/specs/2026-10-12-studio-design.md`。授权：本地实现和验证、Sites 注册/必要源码同步/公开发布；主仓不自行 commit/push。保护并发会话现有文件。

## 1. 运行合同与 Codex 接入

新增 `src/studio/types.ts`、`measurement.ts`、`codex.ts`、`runner.ts` 和 `tests/studio-*.test.ts`。
先测试配置验证、文本计时、usage 分离、JSON-RPC 乱序通知/退出/取消，再实现本机 Codex 检测、握手、账号模型检查、独立会话和串行多轮。
通过条件：mock 协议证明 TTFT 不含启动时间，不输出凭证，失败/取消不计为成功。验证命令 `pnpm exec vitest run tests/studio-*.test.ts`、`pnpm typecheck`。

## 2. 本地配对服务与桌面壳

新增 `src/studio/bridge.ts`、`apps/desktop/{package.json,src/main.ts,src/preload.ts,scripts/build.mjs,electron-builder.yml}`。
本地确认配对、Origin/Host/令牌校验、请求体/运行数量限制、运行状态读取、取消与退出清理。桌面使用本地打包页面、隔离 IPC、平台 Codex 可执行文件定位。
测试错误 Origin/Host、未认证操作、错误/过期配对码、拒绝确认、重复运行与令牌撤销。
验证：focused tests、desktop typecheck/build、Mac 软件启动；跨平台安装包构建分别记录。

## 3. 共用网页

新增 `apps/site/` React + Vite 页面，固定测速 API，通过 desktop preload 或 loopback HTTP 使用同一状态合同。
配置/开始/取消、连接说明、Codex 状态与模型、实时曲线、输出、多轮表格、本地历史、导入和 JSON/CSV/HTML 导出、三平台下载。
设计：深蓝灰底 #101820，面板 #18232d，文字 #e8eff3，辅助 #8ea2b1，蓝 #6fc4ff，橙 #ffb86b；标题 Avenir Next/system sans、正文系统中文、数字 monospace；主要视觉为以秒为轴的示波器式输出曲线，避免装饰掩盖可读性。
验证：site typecheck/build，桌面/移动视口实测，demo 明确标注为样例；真实配对与一次短 Codex 测速。

## 4. 兼容 CLI 与发行

另一个会话停止修改后，核对最新 `src/client.ts`、`config.ts`、`index.ts`，以最小补丁接入 Codex，添加流式回调/取消使现有 API 共用实现；保持原有命令和输出合同。
新增 `docs/studio.md` 和独立 desktop 构建 workflow，不改动正在优化的 README，必要链接最后串行添加。
验证：`pnpm test`、`pnpm typecheck`、`pnpm lint`、`pnpm build`、`git diff --check`；检查命令副作用（build 生成 dist，安装产生 lock/依赖，不运行自动修复 lint）。

## 5. Sites 发布与验收

`apps/site/.openai/hosting.json` 保存唯一 project_id；只创建一次。在独立发布副本中由 Sites helper 提交/推送确切源码和打包。保存版本、设置 public、部署、回读终态与公开 URL。软件内允许连接的站点来源与发布 URL 一致。
线上验证公开访问、静态资源、连接本机、运行状态和敏感数据不进入站点请求。

## 风险与回滚

- 主仓并发改动：新增目录优先，改共享文件前回读；不 reset/stash/覆盖他人改动，不替他人提交。
- Codex 版本能力/账号权限由真实响应验证，缺少字段显示不可用，不伪造。真实调用仅短样本。
- Windows/Linux 实机不可用时报告验证边界；有构建产物也不等于实机验收。
- 删除本次新增模块及精确撤回连接补丁可回到原 CLI；保留另一个会话修复。Sites 回退使用已保存版本；不要删除站点或已有数据。
