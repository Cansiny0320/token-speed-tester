# 主动测速计量修复与历史会话分析

状态：2026-10-12 用户已批准。仅本地实现与验证，不含 commit、push、发布、部署。

## 主动测速

- 保留服务端输出用量与本地文本估算的区别，在结果和导出中记录估算编码及是否回退。
- 模型解析后再创建分词器，不把 `auto` 当模型分词。未知模型使用现有统一回退编码，明确标注，不能猜测真实编码。
- 首末文本分块间的速度只计首批之后到达的 token；分块计时是客户端可观察吞吐，不代表服务端逐 token 解码。
- 只有完整消息而没有 delta 时，保留文本与用量，但不产生 TTFT、曲线或峰值。旧 CLI 无法表达缺失 TTFT 时拒绝该测速样本。
- 保存 app-server 返回的服务档位，不用当前配置推断历史实际档位。保持默认 3 次快速测试，说明小样本及独立进程、缓存、输出长度对比较的限制。

## 历史功能范围

桌面端和已配对网页新增「历史会话分析」。默认近 7 天，允许指定日期范围；本机扫描当前 `CODEX_HOME`（缺省 `~/.codex`）的 `sessions` 和 `archived_sessions`。不读取登录信息，不触发模型请求，不恢复或修改会话。

以后台任务逐行读取，提供进度、取消与重新扫描。保留已完成统计和覆盖信息；取消与失败明确标记，不作为完整分析。文件发现不能只依赖创建日期目录，必须包含最近更新的旧会话。文件读取采用开始时的快照长度，损坏行、缺失字段和运行中尾行统计为覆盖问题。

### 数据与口径

- 新格式优先使用 `token_usage_record` 的逐请求用量，按 `response_id` 去重；旧格式使用 `token_count` 累计差分，避免重复累计，累计重置单独处理。
- 完成、取消和仍在运行的轮次分别显示。按事件时间筛选，并保留范围前的模型/档位/累计基线，避免跨日会话误算。
- 轮次耗时直接使用完成事件值。`time_to_first_token_ms` 标为「模型首 token 等待」，与主动测速的可见首字延迟分开。
- 可见消息使用完整文本分词与 item 生命周期估算速度，记录编码；零时长和缺失时间不算速度。旧版仅有完成文本的消息不猜起始时间。不生成历史 TPS 曲线或峰值。
- 输出 token 含工具参数等模型输出；不能把扣推理用量全部叫作可见正文。工具耗时可用于观察，但不能简单从整轮相减推出模型耗时。
- 模型、effort、服务档位按事件时有效设置归属；缺失为未知，混用设置的轮次明确标注，不能以当前配置补历史字段。
- 汇总包含样本量、用量、缓存比例、轮次耗时与模型首 token 等待分布、消息速度估算，以及按模型/effort/服务档位分组的结果。

### 数据边界与交互

只返回指标、时间、状态和会话/轮次 ID。正文仅在本机瞬时用于分词，不进入 API、浏览器存储、导出、错误文本；不返回工具参数、文件路径、会话标题或凭证。网页使用已有来源、配对与令牌校验；配对说明包含读取历史统计。

界面提供日期范围、开始/取消、进度、覆盖提示、分组表及会话轮次明细，支持 JSON/CSV 导出。历史数据使用独立报告合同，不混入主动测速报告或其历史记录。

## 已核实约束与取舍

- 本机数据约 6.3 GB，不能一次性读入内存；进度轮询必须在扫描时仍能响应。
- 新格式已有请求用量、轮次时间和消息生命周期，但没有逐 delta 数据。
- 去重覆盖 active/archive、副本和新旧事件的重叠；时间范围按实际事件筛选。
- 无法恢复精确解码速度；历史结果定位为日常体验和用量分析。
- 本地目录错误仅返回受控错误，原始日志不进入网页。

## 验收

回归测试覆盖分块速度、非流式缺失计时、解析后模型、服务档位；历史测试覆盖新旧日志、去重、跨日、累计重置、归档、坏行、取消、缺失字段和正文不泄露。通过项目 lint/typecheck/test/build、网页和桌面检查，并用本机真实数据及页面验证。无外部发布。
